# SOC Incident Response Playbooks

Standardized response playbooks built from real investigations and lab simulations. Each playbook follows the full incident response lifecycle and includes detection criteria, step by step response phases, SIEM detection rules, and escalation criteria.

A playbook exists so every analyst on the team responds to the same incident type consistently, not just the experienced ones.

---

## Playbooks

### 1. Phishing Email Response Playbook
**MITRE ATT&CK:** T1566.001 - Spearphishing via Email  
**Built from:** Real phishing investigation involving a Banco Bradesco impersonation email  
**Covers:** Identification, Containment, Investigation, Eradication, Recovery, Documentation  

[View Playbook](./Phishing-Email-Response-Playbook.md)

---

### 2. Brute Force Attack Response Playbook
**MITRE ATT&CK:** T1110 - Brute Force  
**Built from:** Lab simulation detecting 500+ failed login attempts through Splunk Event ID 4625  
**Covers:** Identification, Containment, Investigation, Eradication, Recovery, Documentation  

[View Playbook](./Brute-Force-Attack-Response-Playbook.md)

## Why Playbooks Matter

Raw investigation skills get you into a SOC. Playbooks show you think at the process level. Both playbooks here are based on real work documented in the project folders of this repo, not theoretical templates.
